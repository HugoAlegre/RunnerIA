Subir archivos (arrastrar o elegir)

En Generar → Crear → Archivos podés arrastrar al recuadro o usar Elegir archivos. Los .feature van directo a la vista previa (sin obligar Analizar). El resto alimenta Analizar.

FormatoUsoNotas
.feature Gherkin directo UTF-8. Revisar → Guardar o Importar como lote.
.pdf, .docx Documentación PDF con texto; Word solo .docx (no .doc).
.txt, .md, .json, .csv, .log Notas / datos Se envían al Analizar junto con Detalle o Jira.
PNG, JPG, … Capturas OCR local o visión LLM si hay API key.

Límite: 20 archivos de documentación, 15 MB por archivo. No: Excel, ZIP, .doc antiguo.

Flujo Gherkin desde archivo

  1. Arrastrá o elegí un .feature (o varios para lote).
  2. Revisá la vista previa; elegí módulo destino si hace falta.
  3. Guardar prueba (un caso) o Importar como lote (varios Feature / # Modulo:).

Flujo automático (con Jira)

  1. Configurar Jira (email + token) y probar conexión.
  2. Generar → Crear → pegar Link Jira.
  3. (Opcional) Documentación y módulo destino.
  4. Analizar — fases: Jira/docs → Mapa → Gherkin.
  5. Revisar preview → Guardar (crea .feature en Features/_pruebas).
  6. Ejecutar desde Runner como cualquier otro caso.

Flujo manual (sin Jira)

  1. Completar Detalle en lenguaje natural (obligatorio).
  2. Elegir módulo destino o crear uno nuevo.
  3. Analizar → Guardar.
Al Guardar, si falta un step SpecFlow, se crea stub en PruebaAutoSteps.cs para completar después. La regresión completa se corre desde Runner, no desde Generar.
